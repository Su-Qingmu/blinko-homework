## 项目简介

NoteFlow 是面向大学生和自学者的 **AI 驱动的轻量级学习笔记平台**，解决学习中的知识碎片化、复习困难、缺乏 AI 辅助等问题。

核心功能：
- 笔记管理（Markdown + 标签）
- 闪念速记（全局快捷键）
- AI 对话助手
- AI 自动评论

## 技术栈速览

**后端**：Node.js + Express + tRPC + Prisma + SQLite
**前端**：Vite + React + Tailwind + React Query
**AI**：OpenAI SDK（gpt-4o-mini）
**部署**：Docker Compose（单容器）

## 8 周开发路线

| 周次 | 阶段 | 任务 | 产出 |
|---|---|---|---|
| 1 | 立项 + 需求 | 写立项书、需求调研 | 文档 1+2 |

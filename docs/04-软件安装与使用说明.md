## 四、安装步骤

### 4.1 方式一：Docker 部署（推荐）

#### 4.1.1 准备工作
确保服务器已安装 Docker 和 Docker Compose：
```bash
# 检查 Docker
docker --version
docker compose version
```

如果未安装：
```bash
# Ubuntu / Debian
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
```

#### 4.1.2 克隆代码
```bash
git clone https://github.com/your-team/noteflow.git
cd noteflow
```

#### 4.1.3 配置环境变量
```bash
cp .env.example .env
nano .env
```

填写以下内容：
```env
# OpenAI 配置（必需）
OPENAI_API_KEY=sk-your-openai-api-key
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini

# 数据库（默认即可）
DATABASE_URL=file:/data/dev.db

# 服务端口（默认）
PORT=4000
```

#### 4.1.4 启动服务
```bash
docker compose up -d --build
```

首次启动会自动：
1. 构建前后端镜像
2. 启动容器
3. 运行数据库迁移
4. 启动 Nginx + Node 服务

#### 4.1.5 验证安装
```bash
# 查看容器状态
docker compose ps

# 查看日志
docker compose logs -f app

# 健康检查
curl http://localhost/health
# 期望返回: {"ok":true}
```

浏览器访问 `http://your-server-ip`，看到登录页即安装成功。

### 4.2 方式二：本地开发模式

#### 4.2.1 克隆代码
```bash
git clone https://github.com/your-team/noteflow.git
cd noteflow
```

#### 4.2.2 安装依赖
```bash
# 一次性安装所有依赖（monorepo）
npm install

# 或分别安装
cd server && npm install
cd ../app && npm install
```

#### 4.2.3 初始化数据库
```bash
cd prisma
npx prisma migrate dev --name init
cd ..
```

#### 4.2.4 配置环境变量
```bash
cp .env.example .env
# 编辑 .env 填写 OPENAI_API_KEY
```

#### 4.2.5 启动开发服务

打开两个终端窗口：

**终端 1：启动后端**
```bash
cd server
npm run dev
# 看到: Server: http://localhost:4000
```

**终端 2：启动前端**
```bash
cd app
npm run dev
# 看到: Local: http://localhost:5173
```

#### 4.2.6 访问应用
浏览器打开 `http://localhost:5173`。

## 五、配置说明

### 5.1 环境变量详解

| 变量 | 必需 | 默认 | 说明 |
|---|---|---|---|
| `OPENAI_API_KEY` | ✅ | - | OpenAI API 密钥 |
| `OPENAI_BASE_URL` | ❌ | `https://api.openai.com/v1` | OpenAI 兼容 API 地址（可指向第三方） |
| `OPENAI_MODEL` | ❌ | `gpt-4o-mini` | 使用的模型 |
| `DATABASE_URL` | ❌ | `file:./data/dev.db` | 数据库连接 |
| `PORT` | ❌ | `4000` | 后端服务端口 |
| `NODE_ENV` | ❌ | `development` | 运行环境 |
| `SESSION_TTL_DAYS` | ❌ | `7` | Session 有效期（天） |
| `BCRYPT_COST` | ❌ | `10` | bcrypt 哈希强度 |

### 5.2 切换 AI Provider

如需使用非 OpenAI 的兼容服务（如通义千问、智谱、月之暗面），修改 `.env`：

```env
# 通义千问示例
OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
OPENAI_API_KEY=sk-your-dashscope-key
OPENAI_MODEL=qwen-plus

# 智谱示例
OPENAI_BASE_URL=https://open.bigmodel.cn/api/paas/v4
OPENAI_API_KEY=your-zhipu-key
OPENAI_MODEL=glm-4-flash
```

### 5.3 切换数据库为 PostgreSQL

修改 `prisma/schema.prisma`：
```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

修改 `.env`：
```env
DATABASE_URL=postgresql://user:pass@localhost:5432/noteflow
```

重新迁移：
```bash
cd prisma
npx prisma migrate dev
```

## 七、数据备份

### 7.1 SQLite 自动备份脚本

创建 `scripts/backup.sh`：
```bash
#!/bin/bash
BACKUP_DIR=/backup/noteflow
DATE=$(date +%Y%m%d_%H%M%S)

mkdir -p $BACKUP_DIR
cp /data/dev.db $BACKUP_DIR/dev_$DATE.db

# 只保留最近 7 天
find $BACKUP_DIR -name "dev_*.db" -mtime +7 -delete
```

加入 crontab：
```bash
crontab -e
# 每天凌晨 2 点备份
0 2 * * * /path/to/scripts/backup.sh
```

### 7.2 手动备份

```bash
# 复制数据库文件
docker cp noteflow-app:/data/dev.db ./backup_$(date +%Y%m%d).db

# 恢复
docker cp ./backup_20260831.db noteflow-app:/data/dev.db
docker compose restart app
```

## 八、使用说明

### 8.1 首次使用

1. 浏览器访问 `http://your-server-ip`
2. 点击「注册」创建账号
3. 用户名：3-20 字符
4. 密码：6-32 字符（含字母+数字）
5. 注册成功后跳转登录页
6. 输入凭据登录

### 8.2 创建笔记

1. 主页右上角点击「新建笔记」
2. 在编辑器输入：
   - 标题（可选，留空则取内容前 30 字）
   - 内容（支持 Markdown：**加粗**、*斜体*、`代码`、```代码块```）
   - 标签（输入后回车，多个标签用回车分隔）
3. 点击「保存」
4. 跳转详情页，自动加载 AI 评论（异步）

### 8.3 Markdown 语法示例

```markdown
# 一级标题
## 二级标题
**加粗** *斜体* ~~删除线~~

- 列表项 1
- 列表项 2

1. 有序列表 1
2. 有序列表 2

[链接](https://example.com)

> 引用文字

\`\`\`javascript
const x = 1;
\`\`\`
```

### 8.4 闪念速记

1. 任意页面按 `Ctrl/Cmd + Shift + N`
2. 弹出快速输入框
3. 输入一闪念（最多 500 字），回车提交
4. 闪念列表点击「升级」可补全为完整笔记

### 8.5 AI 对话

1. 侧边栏点击「AI 助手」
2. 点击「新建对话」
3. 输入问题，按回车发送
4. AI 流式回复（打字机效果）
5. 继续追问，AI 保留上下文

### 8.6 AI 自动评论

- 保存笔记后，AI 自动生成 1-2 条评论
- 评论位置：笔记详情页底部
- AI 评论有「AI」徽标，与用户评论区分

### 8.7 搜索

- 主页顶部搜索框输入关键字
- 搜索范围：笔记内容
- 结果按更新时间倒序展示

### 8.8 标签管理

- 笔记编辑页输入新标签自动创建
- 标签在用户内唯一
- 列表页点击标签可筛选

## 九、常见问题（FAQ）

### Q1: 注册时提示"用户名已存在"
**A**: 用户名在同一实例内唯一，换一个用户名即可。

### Q2: 保存笔记后没看到 AI 评论
**A**: 检查：
1. `.env` 中 `OPENAI_API_KEY` 是否正确
2. 网络是否能访问 OpenAI
3. 查看日志：`docker compose logs app`

### Q3: AI 对话没有流式效果
**A**: 检查 Nginx 配置中 `/api/ai/chat-stream` 路径的 SSE 配置（详见《系统设计报告》）。

### Q4: 忘记密码怎么办
**A**: v1.0 暂不支持密码找回，需联系管理员重置数据库。可执行：
```sql
UPDATE Account SET password = '<new-bcrypt-hash>' WHERE username = 'xxx';
```

### Q5: Docker 容器无法启动
**A**: 
```bash
docker compose logs app    # 查看日志
docker compose down         # 停掉
docker compose up -d --build  # 重新构建
```

### Q6: 端口 80 被占用
**A**: 修改 `docker-compose.yml`：
```yaml
ports:
  - "8080:80"   # 改成其他端口
```

### Q7: 数据是否会丢失
**A**: 数据存储在 Docker volume（`./data`），删除容器不会丢失数据。建议配置自动备份（见第七节）。

## 一、文档说明

本文档基于《项目立项书》对 NoteFlow 的功能和非功能需求进行详细描述，作为系统设计、开发和测试的依据。

**术语定义**：
- **笔记（Note）**：用户主动创建的结构化学习记录
- **闪念（Quick Note）**：临时快速记录的灵感或想法，可后期升级为完整笔记
- **AI 评论（AI Comment）**：AI 自动生成的笔记点评、补充或提问
- **AI 对话（AI Chat）**：用户与 AI 助手的多轮对话

## 二、用户角色与权限

### 2.1 角色定义

| 角色 | 权限 |
|---|---|
| **游客（未登录）** | 仅可访问登录/注册页 |
| **普通用户** | 所有 CRUD 操作，仅限本人数据 |
| **管理员**（可选扩展） | 用户管理、配置管理 |

### 2.2 数据隔离

- **强约束**：用户只能看到自己的笔记、评论、对话
- **实现**：所有查询强制携带 `accountId` 过滤条件

## 三、功能需求

### F1. 用户系统

#### F1.1 注册
| 项 | 描述 |
|---|---|
| 输入 | 用户名（3-20 字符）、密码（6-32 字符）、昵称（可选） |
| 校验 | 用户名唯一、密码强度（至少含字母+数字） |
| 输出 | 注册成功，跳转登录页 |
| 异常 | 用户名已存在、参数校验失败 |

#### F1.2 登录
| 项 | 描述 |
|---|---|
| 输入 | 用户名、密码 |
| 校验 | 密码 bcrypt 比对 |
| 输出 | 设置 session cookie，跳转主页 |
| 异常 | 用户名不存在、密码错误 |

#### F1.3 登出
| 项 | 描述 |
|---|---|
| 操作 | 清除 session |
| 输出 | 跳转登录页 |

#### F1.4 个人中心（基础）
| 项 | 描述 |
|---|---|
| 查看 | 昵称、注册时间、笔记数、闪念数 |
| 修改 | 昵称、密码 |

---

### F2. 笔记管理

#### F2.1 创建笔记
| 项 | 描述 |
|---|---|
| 输入 | 标题（可选，10-100 字符）、内容（必填，markdown）、标签数组 |
| 输出 | 笔记 ID，跳转详情页 |
| 副作用 | 异步触发 AI 自动评论（不阻塞保存） |

#### F2.2 编辑笔记
| 项 | 描述 |
|---|---|
| 输入 | 笔记 ID、新内容 |
| 权限 | 仅创建者可编辑 |
| 输出 | 更新成功 |

#### F2.3 删除笔记
| 项 | 描述 |
|---|---|
| 输入 | 笔记 ID |
| 行为 | 软删除（设置 archived=true，30 天后硬删除） |
| 恢复 | 归档页可恢复 |

#### F2.4 查看笔记列表
| 项 | 描述 |
|---|---|
| 默认展示 | 按更新时间倒序 |
| 过滤 | 类型、标签、关键字 |
| 排序 | 更新时间、创建时间、置顶优先 |

#### F2.5 查看笔记详情
| 项 | 描述 |
|---|---|
| 内容 | markdown 渲染 |
| 标签 | 显示所有关联标签，可点击筛选 |
| 评论 | 用户评论 + AI 评论（合并按时间排序） |

#### F2.6 标签管理
| 项 | 描述 |
|---|---|
| 创建标签 | 输入标签名（1-20 字符） |
| 自动创建 | 创建笔记时输入新标签自动 upsert |
| 删除标签 | 解除关联后删除 |

### F3. 闪念速记

#### F3.1 全局快捷键
| 项 | 描述 |
|---|---|
| 快捷键 | `Ctrl/Cmd + Shift + N` |
| 行为 | 弹出快速输入浮层（无需跳转页面） |

#### F3.2 快速输入

| 输出 | 创建闪念，浮层关闭，toast 提示 |

|---|---|

| 行为 | 内容预填到新建笔记页，可补充标题、标签 |

### F4. AI 评论

#### F4.1 自动触发
| 项 | 描述 |
|---|---|
| 触发时机 | 用户保存笔记成功后 |
| 行为 | 异步调用 AI，生成 1-2 条评论 |

#### F4.3 评论展示
| 项 | 描述 |
|---|---|
| 排序 | 按时间正序 |
| 区分 | 用户评论和 AI 评论分组/区分样式 |

#### F4.4 用户主动评论
| 项 | 描述 |
|---|---|
| 输入 | 评论内容（1-500 字符） |
| 输出 | 评论显示在评论区 |

## 四、非功能需求

### 4.1 性能
| 指标 | 要求 |
|---|---|
| 笔记列表加载 | < 500ms（1000 条数据内） |
| 单条笔记保存 | < 800ms（不含 AI 评论） |
| AI 评论生成 | < 10s（95% 请求） |
| AI 对话首 token | < 3s |

### 4.2 安全性
| 项 | 要求 |
|---|---|
| 密码存储 | bcrypt 哈希（cost=10） |
| Session | httpOnly cookie，有效期 7 天 |
| SQL 注入 | 全部使用 Prisma 参数化查询 |
| XSS | 前端 React 自动转义，Markdown 渲染白名单 |

### 4.3 可用性
| 项 | 要求 |
|---|---|
| 浏览器兼容 | Chrome 90+、Edge 90+、Safari 14+ |
| 响应式 | 桌面优先（≥1280px），平板可用 |
| 错误提示 | 中文友好提示，无裸露技术错误 |

### 4.4 可维护性
| 项 | 要求 |
|---|---|
| 代码规范 | ESLint + Prettier |
| 类型安全 | TypeScript strict 模式 |
| 测试 | 关键路由单元测试 |

## 五、用户流程（核心场景）

### 5.1 用户注册 → 第一次记笔记

```
访问首页 → 点击注册 → 输入用户名密码 → 跳转登录 → 输入凭据 →
登录成功 → 进入笔记列表（空状态）→ 点击「新建笔记」→
输入标题 + 内容 + 标签 → 点击保存 → 跳转笔记详情页
看到 AI 评论（异步加载）→ 完成
```

### 5.2 课堂闪念速记

```
上课时按 Ctrl+Shift+N → 弹出快速输入框 → 输入灵感 →
回车提交 → 浮层关闭 → 下课后进入闪念列表 →
点击某条闪念「升级」→ 跳转笔记编辑页
```

### 5.3 与 AI 助手对话

```
进入 AI 助手页 → 点击「新建对话」→ 输入问题 →
等待 AI 流式回复 → 继续追问 → 对话保存
```

## 六、验收标准

### 6.1 功能验收（按用户故事）

#### US1: 用户管理
- [ ] 可以注册新账号
- [ ] 注册的用户名不能重复
- [ ] 错误的密码显示明确提示
- [ ] 登录成功后跳转到主页
- [ ] 退出登录后无法访问受保护页面

#### US2: 笔记 CRUD
- [ ] 可以创建、编辑、删除笔记
- [ ] 笔记可以关联多个标签
- [ ] 删除的笔记进入归档，可恢复
- [ ] 列表按更新时间倒序，置顶优先

#### US3: 标签
- [ ] 标签名在同一用户下唯一
- [ ] 输入新标签自动创建
- [ ] 点击标签可筛选笔记

#### US4: 闪念
- [ ] 全局快捷键可呼出快速输入
- [ ] 快速输入保存为闪念
- [ ] 闪念可升级为完整笔记

#### US5: AI 评论
- [ ] 保存笔记后自动生成 AI 评论（最多 2 条）
- [ ] AI 评论有明确标识
- [ ] 评论可按时间排序

#### US6: AI 对话
- [ ] 可以创建新对话
- [ ] 对话支持多轮
- [ ] 对话列表显示历史
- [ ] 对话历史持久化

#### US7: 搜索
- [ ] 输入关键字可搜索笔记标题和内容
- [ ] 搜索结果高亮关键字

### 6.2 性能验收
- [ ] 100 条笔记列表加载 < 500ms
- [ ] 单条笔记保存响应 < 800ms
- [ ] AI 对话首 token 返回 < 3s

### 6.3 安全验收
- [ ] 密码以哈希形式存储
- [ ] 未登录无法访问 API
- [ ] 用户无法看到他人数据

## 三、技术选型

### 3.1 选型对比

| 项 | 候选 | 最终选择 | 理由 |
|---|---|---|---|
| 后端框架 | Express / Hono / Fastify / NestJS | **Express** | 简单、生态成熟、答辩易讲 |
| API 风格 | REST / tRPC / GraphQL | **tRPC** | 前后端类型贯通，开发效率高 |
| ORM | Prisma / TypeORM / Drizzle | **Prisma** | 类型安全、迁移友好 |
| 数据库 | SQLite / PostgreSQL / MySQL | **SQLite（开发）/ PostgreSQL（生产）** | 开发零配置，生产可靠 |
| 前端框架 | React / Vue / Svelte | **React 18** | 主流，团队熟悉 |
| 状态管理 | Redux / Zustand / React Query | **React Query** | tRPC 配套，够用 |
| 样式 | Tailwind / CSS Modules / styled-components | **Tailwind** | 快 |
| 编辑器 | vditor / Monaco / textarea | **textarea + react-markdown** | 简化，够用 |
| 部署 | Docker / PM2 / Kubernetes | **Docker Compose** | 单机够用，简单 |

## 四、模块设计

### 4.1 用户模块

#### 数据模型

```prisma
model Account {
  id        Int       @id @default(autoincrement())
  username  String    @unique
  password  String    // bcrypt 哈希
  nickname  String?
  avatar    String?
  role      String    @default("user")
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt

  notes         Note[]
  comments      Comment[]
  conversations Conversation[]
  sessions      Session[]
  tags          Tag[]
}

model Session {
  id        String   @id              // 随机 token
  accountId Int
  expiresAt DateTime
  account   Account  @relation(fields: [accountId], references: [id], onDelete: Cascade)
}
```

#### 关键流程

**注册**
```
前端 POST /trpc/user.register
  → 后端校验参数
  → bcrypt 哈希密码
  → INSERT Account
  → 返回 { success: true }
```

**登录**
```
前端 POST /trpc/user.login { username, password }
  → 后端查询 Account
  → bcrypt.compare(password, hash)
  → 生成 session token (crypto.randomUUID)
  → INSERT Session (expiresAt = now + 7d)
  → Set-Cookie: sid=<token>; HttpOnly
  → 返回 { user }
```

**鉴权中间件**
```
请求到达 → 解析 Cookie 中的 sid
  → 查询 Session
  → 验证未过期
  → 注入 ctx.account
  → protectedProcedure 使用
```

### 4.2 笔记模块

#### 数据模型

```prisma
model Note {
  id        Int      @id @default(autoincrement())
  type      Int      @default(0)     // 0=笔记 1=闪念
  content   String
  archived  Boolean  @default(false)
  top       Boolean  @default(false)
  accountId Int
  account   Account  @relation(fields: [accountId], references: [id], onDelete: Cascade)

  tags     Tag[]    @relation("NoteTags")
  comments Comment[]

  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  @@index([accountId, type, archived])
  @@index([accountId, updatedAt])
}

model Tag {
  id        Int     @id @default(autoincrement())
  name      String
  accountId Int
  account   Account @relation(fields: [accountId], references: [id], onDelete: Cascade)
  notes     Note[]  @relation("NoteTags")

  @@unique([accountId, name])
}
```

#### 关键操作

**创建笔记（含标签 upsert）**
```typescript
const tags = await Promise.all(
  input.tagNames.map(name =>
    ctx.prisma.tag.upsert({
      where: { accountId_name: { accountId, name } },
      create: { name, accountId },
      update: {},
    })
  )
);
return ctx.prisma.note.create({
  data: {
    content: input.content,
    type: input.type === 'note' ? 0 : 1,
    accountId,
    tags: { connect: tags.map(t => ({ id: t.id })) },
  },
  include: { tags: true },
});
```

**列表查询（标签 + 搜索 + 分页）**
```typescript
ctx.prisma.note.findMany({
  where: {
    accountId,
    archived: false,
    ...(tagId && { tags: { some: { id: tagId } } }),
    ...(search && {
      OR: [
        { content: { contains: search } },
      ],
    }),
  },
  include: { tags: true, _count: { select: { comments: true } } },
  orderBy: [{ top: 'desc' }, { updatedAt: 'desc' }],
  take: 50,
  skip: pageIndex * 50,
});
```

### 4.3 评论模块

#### 数据模型

```prisma
model Comment {
  id        Int      @id @default(autoincrement())
  content   String
  isAI      Boolean  @default(false)
  accountId Int?
  noteId    Int

  account   Account? @relation(fields: [accountId], references: [id], onDelete: SetNull)
  note      Note     @relation(fields: [noteId], references: [id], onDelete: Cascade)

  createdAt DateTime @default(now())

  @@index([noteId, createdAt])
}
```

#### 关键操作

**保存笔记后异步触发 AI 评论**
```typescript
// 笔记保存成功后
ctx.prisma.note.create({ ... }).then(async (note) => {
  // 不阻塞返回
  setImmediate(() => triggerAIComment(note.id));
});

async function triggerAIComment(noteId: number) {
  const note = await prisma.note.findUnique({ where: { id: noteId } });
  if (!note) return;

  const completion = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [
      { role: 'system', content: '你是学习笔记助手，对用户的笔记给出 1-2 句有建设性的反馈、补充或问题。' },
      { role: 'user', content: note.content },
    ],
  });

  const aiComment = completion.choices[0].message.content ?? '';
  await prisma.comment.create({
    data: { content: aiComment, isAI: true, noteId },
  });
}
```

### 4.4 AI 对话模块

#### 数据模型

```prisma
model Conversation {
  id        Int       @id @default(autoincrement())
  title     String    @default("新对话")
  accountId Int
  account   Account   @relation(fields: [accountId], references: [id], onDelete: Cascade)
  messages  Message[]
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt
}

model Message {
  id             Int          @id @default(autoincrement())
  role           String       // user / assistant / system
  content        String
  conversationId Int
  conversation   Conversation @relation(fields: [conversationId], references: [id], onDelete: Cascade)
  createdAt      DateTime     @default(now())

  @@index([conversationId, createdAt])
}
```

#### 流式对话实现

```typescript
// 后端 SSE 端点
app.get('/api/ai/chat-stream', async (req, res) => {
  const { conversationId, content } = req.body;

  // 鉴权
  const account = req.account;
  if (!account) return res.status(401).end();

  // 保存用户消息
  await prisma.message.create({
    data: { role: 'user', content, conversationId },
  });

  // 加载历史
  const history = await prisma.message.findMany({
    where: { conversationId },
    orderBy: { createdAt: 'asc' },
    take: 20,
  });

  // SSE 头
  res.setHeader('Content-Type', 'text/event-stream');
  res.setHeader('Cache-Control', 'no-cache');
  res.setHeader('Connection', 'keep-alive');

  // 流式调用
  const stream = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    stream: true,
    messages: [
      { role: 'system', content: '你是 NoteFlow 学习助手。' },
      ...history.map(m => ({ role: m.role as any, content: m.content })),
    ],
  });

  let full = '';
  for await (const chunk of stream) {
    const delta = chunk.choices[0]?.delta?.content ?? '';
    full += delta;
    res.write(`data: ${JSON.stringify({ delta })}\n\n`);
  }

  // 保存 AI 回复
  await prisma.message.create({
    data: { role: 'assistant', content: full, conversationId },
  });

  res.write(`data: [DONE]\n\n`);
  res.end();
});
```

```typescript
// 前端消费
const reader = response.body!.getReader();
const decoder = new TextDecoder();
let buffer = '';

while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  buffer += decoder.decode(value);
  const lines = buffer.split('\n\n');
  buffer = lines.pop() ?? '';
  for (const line of lines) {
    if (line.startsWith('data: ')) {
      const data = line.slice(6);
```

## 七、安全设计

### 7.1 认证安全

| 项 | 方案 |
|---|---|
| 密码存储 | bcrypt（cost=10） |
| Session token | crypto.randomUUID() |
| Cookie 属性 | HttpOnly + SameSite=Lax + Secure（HTTPS） |
| Session 有效期 | 7 天 |
| 登出 | 删除 Session 记录 |

### 7.2 输入安全

| 项 | 方案 |
|---|---|
| SQL 注入 | 100% Prisma 参数化查询 |
| XSS | React 自动转义 + Markdown 白名单 |
| CSRF | SameSite Cookie + tRPC 强制同源 |
| 密码强度 | 前端 + 后端双重校验 |

### 7.3 数据安全

| 项 | 方案 |
|---|---|
| 数据隔离 | 所有查询携带 accountId |
| 权限校验 | 资源操作前验证 ownership |
| API 限流 | （进阶）express-rate-limit |

### 7.4 部署安全

| 项 | 方案 |
|---|---|
| HTTPS | Let's Encrypt + Nginx |
| 防火墙 | 仅开放 80/443 |
| SSH | 密钥登录，禁用密码 |
| 数据库 | 内网访问，不暴露 |

```nginx
server {
    listen 80;
    server_name _;

    root /usr/share/nginx/html;
    index index.html;

    # 前端 SPA
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API
    location /api/ {
        proxy_pass http://localhost:4000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # SSE 支持
    location /api/ai/chat-stream {
        proxy_pass http://localhost:4000/ai/chat-stream;
        proxy_set_header Connection '';
        proxy_http_version 1.1;
        chunked_transfer_encoding off;
        proxy_buffering off;
        proxy_cache off;
    }
}
```
